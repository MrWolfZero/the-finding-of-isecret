# TBOI Secret Room Finder
This is a Python Script that automatically finds Secret Rooms for The Binding of Isaac maps. 
It's currently barebones, and doesn't have a GUI, and you have to manually input your map.txt (It does include a GridMaker!). This is just a passion project to learn more about Github and Python
